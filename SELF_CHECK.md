## Environment limitation

The execution sandbox used to produce this archive has outbound package-registry networking disabled and contains no cached pnpm/Astro dependency tree. Therefore it cannot download pnpm or npm packages. Because a real `pnpm-lock.yaml` must be generated by resolving the exact package graph, this archive intentionally does **not** contain a fabricated lockfile, and the requested clean `pnpm install --frozen-lockfile → pnpm check → pnpm build` chain could not be truthfully executed here.

Do not treat a hand-written partial lockfile as valid. In a network-enabled environment, run:

```bash
./scripts/make-lockfile.sh
./scripts/self-check.sh
```

The first command creates the real lockfile from the exact versions in `package.json`; the second performs the requested clean-environment gate.
